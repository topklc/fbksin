# fbksin

A collection of foobar2000 mobile skins (.fbskin) gathered from around the internet. From forum threads, dead download links, and scattered archives, all mirrored here in one place so they're easy to find and grab.

> None of these skins are my own work. All credit goes to their original authors, who mostly shared them on the Hydrogenaudio/foobar2000 forums. If you're the author of one of these skins and would like credit added, a link included, or a file removed, please open an issue.
